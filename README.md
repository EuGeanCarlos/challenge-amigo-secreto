# Challenge Amigo Secreto

Projeto Alura/ONE para adicionar nomes, remover participantes e sortear um amigo aleatoriamente.

## Tecnologias

- HTML
- CSS
- JavaScript

## Funcionalidades e utilização

Adicione ao menos um nome à lista e clique em Sortear amigo; use o controle de remoção para corrigir participantes.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/challenge-amigo-secreto.git
cd challenge-amigo-secreto
python -m http.server 8000 --directory "."
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.

# 🎁 Challenge Amigo Secreto  

Este é o meu projeto do **Challenge Amigo Secreto** feito no programa **Capacitech - ONE (Turma G9)**.  
A ideia é criar uma aplicação simples usando **HTML, CSS e JavaScript** para treinar os primeiros passos em programação web. 🚀  

---

## 📖 O que o projeto faz  

- Eu digito o nome de um amigo em um campo de texto.  
- Clico no botão **Adicionar** e esse nome aparece em uma lista.  
- Se eu digitar errado, posso **remover** o nome clicando no ❌.  
- Quando já tenho nomes na lista, clico em **Sortear Amigo** e o sistema escolhe 1 de forma aleatória. 🎉  

---

## 🛠️ Tecnologias utilizadas  

- **HTML5** → para estruturar a página.  
- **CSS3** → para deixar a página mais bonita.  
- **JavaScript** → para fazer a lógica (adicionar, remover e sortear os amigos).
